# Clinical Product Catalog UI Demo

A small React interface prototype for viewing a sample catalog on desktop and mobile screens.

**[Open the live demo](https://demo-screen-ivory.vercel.app)**

## About

The page displays a pair of hard-coded example listings. The catalog data is illustrative only: this project is a user-interface demo, not a real medical product catalog, clinical service, or source of health advice.

## Run locally

1. Install Node.js.
2. Run npm install.
3. Run npm start.
4. Open the local URL printed by Create React App.

This project was created with Create React App.
